# MuseDraw 品牌资产

标识由字母 **M** 与两片展开的图纸折面构成。深色部分建立轮廓，蓝色折面作为识别色；字标保持简洁，适合仓库首页和小尺寸应用。

## 资产

| 文件 | 用途 |
| :--- | :--- |
| [musedraw-cover.png](musedraw-cover.png) | README 主视觉品牌封面，3344 × 1882 |
| [wordmark-light.svg](wordmark-light.svg) | 浅色背景的横向字标 |
| [wordmark-dark.svg](wordmark-dark.svg) | 深色背景的横向字标 |
| [mark.svg](mark.svg) | 独立图标 |
| [mark-mono.svg](mark-mono.svg) | 单色图标 |

矢量字标与图标为项目原创 SVG，背景透明，仍可用于独立标识和小尺寸展示。颜色和形状直接保存在文件中，无需联网加载字体或图标库。

README 使用已确认的 PNG 品牌封面。封面以项目创作的图像和图示为素材，通过图像辅助合成，再用 HTML/CSS 排定中央标题与标语。它是品牌视觉，不是画廊作品的逐像素截图拼接，也不代表所有元素都提供 SVG 源文件。

这些项目自制品牌资产沿用仓库的 [Apache-2.0 许可](../../LICENSE)。

## 使用

- 保持原有比例，不拉伸、倾斜或附加阴影。
- 图标建议不小于 24 × 24 像素，四周留出至少图标宽度四分之一的空间。
- 主要色：墨色 `#182235`、蓝色 `#315DE6`；深色背景字标使用浅墨色与浅蓝色。
- 独立字标与图标优先使用 SVG，品牌封面使用原始 PNG。展示品牌不代表软件质量认证或第三方背书。

# 数据平台示例审核

审核对象：[brief](brief.md)、[SVG](diagram.svg)、[PNG](diagram.png)。这是通用能力参考，不是实施方案或工程认证。

## 实际观察

已实际查看完整 1920 × 1232 PNG，并核对 SVG 的原生文本、画布与 `capability-containment` 元数据。

- 四层主体、两侧支撑和底部来源/基础设施角色不同；没有用箭头把能力表误画成请求流程。
- 数据服务层是主要强调区；白子块与浅色分组保持内部层级，其余层不各自换一种鲜艳颜色。
- 门户与主体短标签采用横向排列；侧支撑贯穿多层，不向每个能力重复连线。
- 同层组等宽来自当前固定渲染器；这不是所有平台都应等宽、都有门户或双侧栏的设计要求。

## 复现与验收

在仓库根目录运行 `python scripts/check.py`，再按 README 的可选浏览器预览说明检查实际字体边界。常规本地检查不依赖 Playwright；未执行的浏览器检查应明确记录。

本记录的实际看图不替代另一环境的渲染验证。查看原尺寸、密集区域与目标缩小尺寸；手机缩图不保证全部正文可读，必要时另交局部。程序通过不等于用户审美认可。

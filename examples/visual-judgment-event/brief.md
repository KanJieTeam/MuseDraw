# 活动信息的组织对照

虚构社区活动的原创设计练习，不是真实报名通知。用同一内容制作1200×900的中文信息海报：

- 主题：把旧物讲成新故事；说明：一场修补与分享的小聚。
- 2026年11月7日，14:00—17:30。
- 梧桐社区阅览室。
- 免费、需预约、限30席、适合12岁以上。
- 请自带一件愿意修补的小物。
- 不编造二维码、网址或联系人。

观看任务：先发现活动主题，再找到时间地点及影响参与的条件。研究问题是语义分组怎样帮助条件被一起发现，不是检验观者是否喜欢米色。

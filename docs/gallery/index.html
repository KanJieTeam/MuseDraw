示例展示画法。你的行业、组件名称与关系，可以完全不同。

安装到你的智能体

按提示选择客户端，在能读写文件、执行工具的智能体中使用。

npx skills add KanJieTeam/MuseDraw

说主题、关系和风格

提供已有资料；想构思通用示例时，说明“通用参考”。无需坐标、色值或绘图代码。

用 MuseDraw 画一张医院预约系统组件图，使用手绘线稿。患者端提交请求到预约服务，预约服务查询排班并写入预约库。给方案说明使用。

在对话中继续修改

“把预约服务改名为预约管理服务，其他关系不变。”也可以新增组件、调整关系或切换风格。交付 PNG、可编辑 SVG 与语义文档。

保存文档，可以重做同一张图。

下载 document.json，让智能体用 MuseDraw 重渲染。同一份文档在相同绘图版本、字体与运行环境下可重复生成相同原生几何；PNG 抗锯齿可能有微小差异。让另一个模型只凭短需求重新理解与绘图，则不能保证完全相同。

PNG 需要已有 Node.js 22+、Playwright、Chromium 兼容浏览器及相应字体。MuseDraw 不额外要求模型 API key。当前支持组件、显式关系与平面归属域；嵌套域等结构尚未支持。

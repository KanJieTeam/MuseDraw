# 选择画法

[在线入口](https://kanjieteam.github.io/MuseDraw/)只展示当前两种代码驱动风格：手绘线稿、终端色域。
每种风格一张实际模型生成图，提供 PNG、SVG 与语义重画文档。点击“用这个风格”
复制几句话给你的智能体，再改成自己的系统内容。页面不收集密钥，也不是在线模型聊天框。

两张图不是两个业务模板。新主题由模型整理组件和已知关系，同一绘图工具负责执行。
已有语义文档可在同版代码和字体条件下原样重绘；新需求理解与跨平台 PNG 不承诺百分百。

旧100张制作案例已撤下公开图集和安装参考；历史文件可从 Git 历史恢复。
完整测试状态保留在[验证记录](../verification/graph-workflow-20261014/README.md)，不在页面重复凑图。

# E09 HTTP 状态码

类别：工程 · 瑞士海报　画布：1600 × 1100

## 简短需求

瑞士海报风格的 HTTP 状态码速查：1xx 到 5xx 五栏，每栏列常用状态码和一句话含义。

## 原始需求

前后端联调时总有人问 401 和 403 有什么区别，想做一张贴在工位上的状态码速查：五大类各列常用的几个，英文原名加一句中文解释。

## 设计决定

- 五栏等宽，每栏顶部一个超大的「1xx—5xx」，4xx 与 5xx 用红色，一眼区分「是谁的问题」。
- 每个状态码三行：数字、英文原名、一句中文；中文解释写成人话，如「登录了，但没权限」。
- 严格左对齐网格，只用红、黑、白。
- 底部一句排查建议。

## 事实与数据

- 状态码含义按 RFC 9110；429 定义于 RFC 6585。

## 导出预期

- 元素 74 个，其中原生文字 67 个。
- 只用纯色填充、描边和原生文字，无渐变、裁切、蒙版、滤镜。
- 不依赖文字被形状遮挡，现有导出顺序不影响画面。

## 已知弱点

- 只列常用状态码，307、308、422 等未列出。

# 负载均衡算法的尾延迟

用途：科研。风格：科研期刊。

## 表达方法

设置→分布→结论。三面板围绕同一实验问题展开，算法颜色在分布与尾延迟图中保持一致。

## 原作者的设计决定

- 期刊图版式：小写面板字母、细坐标轴、浅灰网格，图注用宋体放在图下。
- c 用对数纵轴，否则轮询在接近稳定上限时的 p99 会把其他曲线压扁。
- 慢服务器用斜线填充区分，不靠颜色。

## 使用边界

模拟与结论须能复算；原包的计算说明尚未由本轮独立重跑。

# T03 解一元一次方程

类别：教学 · 白板手绘　画布：1600 × 1000

## 简短需求

白板手写：一道含分母的一元一次方程，按五步解出来，易错的地方用红笔标出。

## 原始需求

七年级数学，讲含分母的一元一次方程。想要像老师在白板上边讲边写的效果：左边是步骤名，右边是每一步的式子，红笔标去分母和变号这些易错点，最后绿笔检验。

## 设计决定

- 白板四周是银灰边框，板面留几块擦过的淡灰痕迹。
- 用四种白板笔颜色分工：黑色写式子，蓝色框步骤名，红色写易错提醒，绿色写检验；红圈圈住最后答案。
- 方框、下划线、圆圈都由抖动曲线画成，四边不闭合得太整齐，接近手写。
- 例题用竖式分数，后面各步按老师实际板书写成一行一个式子。

## 事实与数据

- 例题 (x + 1)/2 − (2x − 1)/3 = 1，解得 x = −1；代入检验左边 = 0 − (−1) = 1。

## 导出预期

- 元素 49 个，其中原生文字 25 个。
- 只用纯色填充、描边和原生文字，无渐变、裁切、蒙版、滤镜。
- 不依赖文字被形状遮挡，现有导出顺序不影响画面。

## 已知弱点

- 式子用 TeX Gyre Pagella 排版，不像真正的手写字。
- 红色提醒只有两行，较长的解释放不下。

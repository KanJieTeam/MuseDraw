# 153 二进制

- 用途：教学
- 风格：终端暗色
- 画布：1600 × 1000
- 主题：教学（中学）

## 简短需求

用终端和八位指示灯讲二进制：除二取余、按权展开、二进制加法，以及一个字节能表示多少种状态。

## 原始需求

七年级信息科技：数据的编码。左边像在 Python 里一步步算：13 的除二取余、1101 的按权展开、0101 + 0011 的进位；右边是 8 个指示灯显示 13，下方是 0 到 8 的二进制对照。

## 设计决定

- 终端暗色：注释、输入、输出三种颜色；亮起的位用琥珀色，与输出结果同色。
- 指示灯下面写位权 128 到 1，让“按权展开”可以直接对着灯读。

## 事实与数据

- bin() 是 Python 的内置函数，返回带 0b 前缀的二进制字符串。
- 8 位二进制可表示 2⁸ = 256 种状态（0–255）。

## 由程序计算或核对

- 除二取余步骤由循环生成，程序断言余数倒序为 1101，且等于 bin(13)；断言 0101 + 0011 = 1000。
- 0 到 8 的二进制对照表由 format(i, "04b") 生成。

## 导出预期

- SVG：原生矢量，5 个图层（背景、窗口、除二取余、按权展开、八位指示灯），文字为可编辑文本，无外链、无脚本。
- PNG：由 Chromium 按 1 倍尺寸渲染。

适合进入 Skill 的内容

  1. 主题成为主视觉。补书成为一本待修的书，爵士节用节奏点阵；先找内容中的对象与动作，再作抽象。
  2. 关系决定构图。多层检索用对应平面，支路汇合用路线，并列论证与递进论证使用不同结构。
  3. 证据之间保持对应。多面板共享对象、颜色和尺度；孔板、命中列表与统计必须来自同一数据。
  4. 信息密度有主次。标题先说具体发现，关键对象保留对比，其余退为背景；不要求所有图都简洁到空洞。
  5. 材质与风格有出处。纸、粉笔、订线、河网、夜色服务主题；不用每张都加渐变、印章或手绘抖动。
  6. 修改内容时重算。日历、排名、累计量、检索路径、时间安排都需要内容驱动，不能仅替换文字。

让别人实际用起来

  1. 案例：保留原生 SVG、PNG、简短需求与设计决定，先交付可看的成品与可编辑源稿。
  2. 方法：每种方法附输入字段、构图规则、长内容处理、适用条件和失败边界。
  3. 模板：将日期、数据、标签、段落数量与计算逻辑参数化，再换一组内容实测。
  4. 入口：按海报、数据图、关系图、科研多面板等产物选择制作方式，保留各自的标题、字体和密度需求。

## 原作者的设计决定

- 系统边界用虚线框，框内五个容器统一为浅蓝方框，数据库画成圆柱；每个容器写技术栈和一句职责。
- 外部系统放在边界下方一排，灰色；连线按 C4 惯例写动作和协议。
- API 服务居中，所有外部对接都从它出发，读者能看出它是唯一的集成点。
- 图例包含人员、容器、数据库、外部系统四种。

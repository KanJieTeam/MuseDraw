# O01 会议室预订系统　容器图

类别：办公 · C4 标准　画布：1600 × 1080

## 简短需求

用 C4 容器图画公司的会议室预订系统：Web、移动端、API、数据库、通知服务，以及日历、单点登录、门禁三个外部系统。

## 原始需求

行政部和 IT 一起做会议室预订系统，要给供应商一张 C4 容器图：系统里有哪些部分、用什么技术、和企业日历、单点登录、门禁怎么对接。

## 设计决定

- 系统边界用虚线框，框内五个容器统一为浅蓝方框，数据库画成圆柱；每个容器写技术栈和一句职责。
- 外部系统放在边界下方一排，灰色；连线按 C4 惯例写动作和协议。
- API 服务居中，所有外部对接都从它出发，读者能看出它是唯一的集成点。
- 图例包含人员、容器、数据库、外部系统四种。

## 事实与数据

- EWS 为 Exchange Web Services，SAML 为单点登录常用协议；架构为示例。

## 导出预期

- 元素 103 个，其中原生文字 62 个。
- 只用纯色填充、描边和原生文字，无渐变、裁切、蒙版、滤镜。
- 不依赖文字被形状遮挡，现有导出顺序不影响画面。

## 已知弱点

- Web 应用、移动端到 API 的箭头没有全部写标签，只在中间一条写了「调用」。

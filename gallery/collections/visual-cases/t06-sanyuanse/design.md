# 三原色与间色

用途：教学。风格：包豪斯。

未作单图深审。已看缩略成品，尚未进入本轮优先深审；不等于质量不合格。

## 原作者的设计决定

- 三原色配三种基本形：黄三角、红方块、蓝圆，对应康定斯基 1923 年在包豪斯做的形状与颜色问卷。
- 混色用两个重叠的圆表示，重叠的透镜形区域直接涂成间色；透镜由两段圆弧计算得到，没有使用裁切。
- 只用原色、黑色粗条和米白底；标题一粗一细两种字重，黑色竖条和横条把画面切成上下两层。
- 右下角六色色环按红橙黄绿蓝紫排列，正对的两色就是互补色。

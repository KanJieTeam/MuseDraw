# 120 GitOps 拉取式部署

- 用途：工程
- 风格：柔和笔记
- 画布：1600 × 1000
- 所属：第 6 包（云原生与运维）

## 简短需求

用手账式的柔和笔记画出 GitOps 的拉取式部署循环，以及集群被手动改动后如何被拉回。

## 原始需求

给团队分享 GitOps：开发者合并 PR，Argo CD 拉取 Git、比对、同步到集群；有人手动改集群时会被发现并修复；旁边用便签写推与拉的区别、回滚和审计。

## 设计决定

- 柔和笔记：点阵纸底，粉黄绿蓝四种荧光笔色块，卡片边线带轻微抖动。
- 主循环横向走两层：上层是“改 Git”，下层是“改集群”，漂移从左下方插入。
- 便签纸轻微旋转，只在便签下垫一层很淡的错位底色。

## 事实与数据

- Argo CD 默认每 180 秒（timeout.reconciliation）检查一次 Git，也支持 Webhook 触发。
- 应用状态与 Git 不一致时显示为 OutOfSync；开启 selfHeal 的自动同步策略会把手动改动改回去。

## 由程序计算或核对

- 无数值计算。

## 导出预期

- SVG：原生矢量，7 个图层（背景、点阵纸、标题、节点、箭头、批注、便签），文字为可编辑文本，无外链、无脚本。
- PNG：由 Chromium 按 1 倍尺寸渲染。

## 已知弱点

- 没有手写体中文字体，笔记里的字仍是印刷体。

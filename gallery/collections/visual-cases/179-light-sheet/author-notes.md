# 179 光片荧光显微镜

- 用途：科研
- 风格：产品发布
- 画布：1600 × 1000
- 主题：科研（复杂多面板）

## 简短需求

用发布会的方式介绍光片荧光显微镜：正交的照明与检测光路、光片的厚度与视野，以及两者之间由高斯光束决定的权衡。

## 原始需求

显微成像方法配图：左侧是检测物镜、照明物镜和样品室的示意，光片按高斯光束腰的形状绘制并标出厚度与视野；右侧是 488 nm 和 561 nm 两种波长下光片厚度与可用视野的关系曲线；底部是几个关键数字。

## 设计决定

- 产品发布：纯黑背景、白色大字，光片是唯一发光的青色元素。
- 光片外形按 w(z) = w₀√(1 + (z/z_R)²) 绘制，厚度方向放大以便看清。

## 事实与数据

- 高斯光束的瑞利长度 z_R = π w₀² n / λ；光片的可用视野常取 2z_R。
- 光片显微镜只照亮焦平面附近，因此光漂白和光毒性低于宽场照明。

## 由程序计算或核对

- 在水中（n = 1.33），w₀ = 2 µm、λ = 488 nm 时 2z_R = 68.5 µm，561 nm 时 59.6 µm，程序断言在 60–75 µm。
- 100 µm 厚样品中被 4 µm 光片照亮的比例为 4%。
- 右侧曲线按同一公式逐点计算。

## 导出预期

- SVG：原生矢量，5 个图层（背景、标题、原理图、权衡曲线、参数），文字为可编辑文本，无外链、无脚本。
- PNG：由 Chromium 按 1 倍尺寸渲染。

## 已知弱点

- 没有画扫描光片、贝塞尔光束等拓展视野的方法。
- 物镜和样品室是高度简化的示意。

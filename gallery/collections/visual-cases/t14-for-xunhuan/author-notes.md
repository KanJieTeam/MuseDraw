# T14 for 循环的执行过程

类别：教学 · 终端暗色　画布：1600 × 1000

## 简短需求

终端暗色风格：一段四行的 Python 求和代码，配逐轮追踪表和输出结果。

## 原始需求

高一信息技术讲 Python 的 for 循环，学生总搞不清循环体执行了几次。想要一张终端风格的图：左边是代码和运行结果，右边一张表逐轮写出 i 和 total 怎么变。

## 设计决定

- 配色采用常见的暗色编辑器配色：关键字红、函数紫、数字蓝，当前反复执行的第 3 行加深色高亮。
- 两条流程箭头画在代码框两侧：右侧琥珀色表示回到第 2 行，左侧蓝色表示取完后跳到第 4 行。
- 追踪表逐轮列出 i、执行前与执行后的 total，最终值 15 由程序计算并与输出一致。
- 标题与说明都写成 Python 注释，全图只用等宽字体。

## 事实与数据

- range(1, 6) 依次给出 1、2、3、4、5；累加结果为 15。

## 导出预期

- 元素 51 个，其中原生文字 42 个。
- 只用纯色填充、描边和原生文字，无渐变、裁切、蒙版、滤镜。
- 不依赖文字被形状遮挡，现有导出顺序不影响画面。

## 已知弱点

- 终端提示符和光标是装饰性的。

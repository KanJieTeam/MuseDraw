# 143 血液循环线路图

- 用途：教学
- 风格：地铁线路
- 画布：1600 × 1000
- 主题：教学（中学）

## 简短需求

把人体血液循环画成地铁线路图：肺循环在上、体循环在下，在心脏四个腔“换乘”，线的颜色表示动脉血和静脉血。

## 原始需求

七年级生物：人体内的血液循环。用两条环线表示肺循环和体循环，标出心房、心室、主要血管和毛细血管；突出肺动脉里流静脉血、肺静脉里流动脉血这个易错点。

## 设计决定

- 地铁线路：两条环线在心脏处换乘，心房到心室的换乘通道标注为房室瓣。
- 线路颜色不按“线路”而按血液成分分段，红蓝在毛细血管处切换，易错点因此一目了然。
- 图中按惯例以观察者的左侧表示身体右侧。

## 事实与数据

- 体循环：左心室 → 主动脉 → 各级动脉 → 全身毛细血管 → 各级静脉 → 上、下腔静脉 → 右心房。
- 肺循环：右心室 → 肺动脉 → 肺部毛细血管 → 肺静脉 → 左心房。

## 由程序计算或核对

- 无数值计算；线路只走水平、竖直和 45 度。

## 导出预期

- SVG：原生矢量，6 个图层（背景、心脏底、线路、心脏、车站、标题与图例），文字为可编辑文本，无外链、无脚本。
- PNG：由 Chromium 按 1 倍尺寸渲染。

## 已知弱点

- 心脏画成四个车站，没有画真实的解剖形态和动脉瓣。
- “动脉血鲜红、静脉血暗红”用红蓝两色表示，是教学惯例而非真实颜色。

# T09 三类杠杆

类别：教学 · 工程蓝图　画布：1600 × 1000

## 简短需求

用工程蓝图的样子画三类杠杆：省力、等臂、费力，标出动力臂、阻力臂和平衡条件。

## 原始需求

初二物理《杠杆》，想做成工程图纸的样子：三种杠杆并排，支点、动力、阻力画清楚，动力臂和阻力臂用尺寸线标出来，再各举一个生活中的例子。

## 设计决定

- 底色是蓝图蓝，20 像素细网格加 100 像素粗网格，双线图框，右下角是工程图纸标题栏。
- 每个杠杆的长度都按 400 像素等于 1 米画，动力臂、阻力臂用带界线和双向箭头的尺寸线标注，数值与图形一致。
- 支点画成三角支座加地面剖面线；被撬的石头、天平托盘用虚线，表示是附加示意。
- 每格下方写出 L₁ 与 L₂ 的关系，再给出由杠杆平衡条件算出的 F₁ 与 F₂ 的倍数关系。

## 事实与数据

- 杠杆平衡条件 F₁L₁ = F₂L₂。撬棍：L₁ = 0.8 m、L₂ = 0.2 m，F₁ = F₂/4；天平等臂；镊子类：L₁ = 0.3 m、L₂ = 1.0 m，F₁ ≈ 3.3 F₂。

## 导出预期

- 元素 261 个，其中原生文字 39 个。
- 只用纯色填充、描边和原生文字，无渐变、裁切、蒙版、滤镜。
- 不依赖文字被形状遮挡，现有导出顺序不影响画面。

## 已知弱点

- 镊子画成抽象的杆，没有画出镊子本身的形状。

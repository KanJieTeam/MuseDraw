# 115 订单服务部署图

- 用途：工程
- 风格：C4 标准
- 画布：1600 × 1000
- 所属：第 6 包（云原生与运维）

## 简短需求

按 C4 部署图画出订单服务在三个可用区的部署：负载均衡、K8s 节点池里的容器、托管数据库及复制关系。

## 原始需求

给架构评审用的部署视图：一个区域三个可用区，每个可用区有 Web 前端和订单 API，数据库主库在 A、同步备库在 B、只读副本在 C，标出访问、调用、读写和复制关系。

## 设计决定

- 严格使用 C4 记法：人员深蓝、容器中蓝、部署节点为灰色描边框，名称和类型写在左下角，关系为带技术说明的虚线箭头。
- 部署节点嵌套三层（区域、可用区、节点池或数据库实例），节点池和数据库实例用虚线框区分层级。
- 跨可用区的读写线汇成一条走廊，只标注一次。

## 事实与数据

- C4 部署图用于展示容器实例如何映射到基础设施（部署节点）。
- 版本号（Kubernetes 1.30、Java 21、PostgreSQL 16）为示例。

## 由程序计算或核对

- 无数值计算。

## 导出预期

- SVG：原生矢量，7 个图层（背景、标题、人员、部署节点、容器、关系、图例），文字为可编辑文本，无外链、无脚本。
- PNG：由 Chromium 按 1 倍尺寸渲染。

## 已知弱点

- 三个可用区里的 Web 到 API 关系只在可用区 C 标了一次说明。
- 没有画出出站依赖（支付网关等外部系统），完整评审时需要补一张系统上下文图。

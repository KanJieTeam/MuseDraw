# Herbarium / 植物图谱

> 用 MuseDraw 深林绿色植物学图版，以一株原创想象植物为主体。画出连续分枝、锯齿叶缘、主脉支脉、小伞形花序和种子细节；米黄与鼠尾草绿墨色。保留图谱的细读层次，不虚构物种名称。

本例是原生可编辑矢量作品。精确重放请渲染同目录 `scene.json`；短提示词表达创作方向，不保证逐像素复现。

This is original vector artwork. Edit the native shapes and text in `scene.json`; rendering the scene preserves the composition.

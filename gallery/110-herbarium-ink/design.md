# Design decisions

A single branching specimen provides the hierarchy; veins and flower clusters reward closer reading.
The drawing is invented and is explicitly not a taxonomic key. Leaf attachment follows branch positions; marginal detail and restrained annotations support the main specimen.

Original vector interpretation of a visual language in the author-supplied MuseDraw brand moodboard. All shapes and text are editable. This is an art-directed scene, not a promise that a short prompt reproduces the same composition. No external images or fonts are embedded.

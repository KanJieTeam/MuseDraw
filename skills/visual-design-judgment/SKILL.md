# 从意图到视觉决定

把用户想让人看懂、感到或采取的行动，变成具体的空间、形态、节奏与对象关系。直接从普通语言开始，不要求用户先选流派、模板编号或坐标。

这是一层设计判断，不是渲染器。沿用当前任务已有的源文件、工具和验收规则。与 MuseDraw 同用时，在现有场景、主题与输出流程中应用可表达的决定；不绕过其导出流程，也不为普通出图额外强制视觉服务、OCR、上传或整套审稿。支持某种构思不等于产品已实现该媒介的完整绘制能力。

## 找到当前的表达问题

按实际问题选择相关内容，不把全部规则逐项套用：

| 用户需要 | 先解决什么 | 相关参考 |
|---|---|---|
| 解释、比较、快速查阅 | 误解在哪里；数量、关系、归属还是顺序 | [信息与阅读](references/information.md) |
| 文学性、古典、浪漫、含蓄、情绪 | 想改变哪种观看经验；哪些关系必须明确 | [情绪与形式](references/aesthetic-decisions.md) |
| 观念插画、无字故事、分镜 | 意义是否有可见依据；动作怎样改变状态 | [关系与叙事](references/relations-and-staging.md) |
| 改善作品或视觉审稿 | 哪个具体问题阻碍目标；最小修复是什么 | [诊断与修改](references/diagnosis.md) |

同一作品可以混合意图；功能事实仍须完整。未知事实会改变设计时针对性询问，常规构图由创作者判断。只需一个成品时不默认输出多套方向。

## 保留变化的理由

让共同语法承担身份，让差异承担真实的内容变化。内容角色不同时，区域可以不等大；比较任务需要稳定参照时，保留等格和一致尺度。先看基线、字面、比例、间距与密度怎样组织信息，再判断边框是否确实表达归属、容器或状态。

不要把文学性固定成米色、衬线、纸纹、月亮和空椅，也不要把反模板固定成禁止卡片、对称或装饰。明亮、拥挤、幽默与华丽都可能适合当前意图。参考作品提供可检验的思路，名气不能代替理由。

## 在原任务内实现并交付

局部修改先确定改变什么、保留什么；稳定对象身份，只协调受该变化影响的部分。风格调整不更改事实、数量、角色或关系。用户已经选定方向时，不因本 Skill 自动重做整幅。

把事实与编码、意图适配、工艺、偏好分开判断。渲染成功、无碰撞和标签齐全分别只证明其实际检查项。被要求视觉审稿时，记录实际看到的问题；没有看图，不宣称视觉检查通过。日常交付只需简短说明关键取舍和实际完成的检查。

本模块的方法来自跨媒介与文学研究，是有适用条件的设计建议。现有小样本模型对照只发现局部收益，尚未证明整体审美提升。需要评估或研究溯源时读 [证据与边界](references/evidence.md)，不默认加载研究账本。

# 诊断与最小修改

用于用户要求的审稿，或创作中已发现的具体问题。普通小改动不必附完整评估表。

## 先描述，再判断

说明实际看见的位置、形态或状态，再说它怎样影响任务。区分：

- **事实或编码错误**：标签数值与几何矛盾、关系反向、角色状态违背给定情节。能与输入核对。
- **工艺问题**：字难读、接触不清、路由重叠、空间不一致。指出可见后果与不确定性。
- **意图与解释**：某种关系支持一种读法，也可能支持另一种。无唯一含义不自动是错。
- **个人偏好**：喜欢冷暖、繁简、题材或气质。标明观看目的，不冒充事实要求。

有证据才报告错误；未发现不等于证明没有。看不清的局部可以标为待确认，不推断出根本不存在的对象。

## 让意见可执行

用“位置 → 可见观察 → 当前要求 → 后果 → 最小修复”组织必要反馈。例如：“末格石头与纸之间留着空隙，不能支持已经压住纸的状态；先修接触与投影，再评风格。”不要只说更高级、更浪漫、更有呼吸感。

图面越漂亮越不应掩盖方向、数值和状态错误；同样，也不为证明审稿认真而强找缺点。结论可为可用、需修改或待确认，不强制总分和唯一名次。

## 判断方法的边界

先无题目阅读再提供题目，有助于发现解释依赖，但不是人类眼动或真实受众测试。配对时隐藏条件与作者、稳定题目和工具，保留相近、两者均需修改与分歧。两个模型的多次判断不能换算成多名真人。

已知错误校准只说明评审能否定位该组问题；不能证明新阅读带来了该能力。若要声称产品改善，应另跑真实产品链路，而非只用专用SVG脚本。

来源方法启发：[Getty摄影分析教学材料](https://www.getty.edu/education/for_teachers/curricula/exploring_photographs/background1.html)、[休谟的比较与反复观看](https://davidhume.org/texts/empl1/st)。这里的错误分类和修改办法为原创操作性整理，不是对这些作者方法的完整复刻。

# 本地发行预演

等宽节奏围绕实际输入、日志与生成文件展开。绿色代表真正完成的本地检查；错误保持可修正。终端外观不能替代操作，未运行的测试与发布不能写进成功日志。

## 使用与改编

复制完整目录，直接打开 `index.html`。HTML/CSS/JavaScript 是可编辑源；相邻 `data.json` 记录示例输入，实际页面数据嵌在 `study-data` 脚本块中，改数据时同步更新。换主题时重写语义内容并核实标题，不只改标题文字。

先看 `preview.jpg` 和 `prompt.md`。保留虚构/概念示意的说明，真实任务需替换事实及来源。系统字体会改变字形与换行；以实际出图为准。此范例经过本机看图检查，非跨模型稳定提升证明。

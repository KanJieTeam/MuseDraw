# 共享空间观察 · 孔版套印报告

> 使用 MuseDraw 的孔版套印风格，把随附 data.json 做成一页横版办公报告，标题「一间空间，两种节奏」。在共同时间坐标上比较工作日示例与周末示例，计算各自峰值及其发生时刻，并显示峰值时刻差。保留实际观测时刻和数值，图像叠色可以出现在曲线与零基线之间，测量标记保持清楚。不要把图层堆叠成总量，也不要抖动数据来模拟印刷。所有数据为虚构演示，保留说明。交付报告图片、原始数据、计算结果与可编辑排版。

随附 `data.json` 为完整原始数据。使用 Skill 中的 `scripts/build_visual_report.py`
把它构建到新输出目录，再在浏览器导出 1800 × 1200 报告。
本目录 `index.html`、`report.css`、`chart.png` 是直接可看的原稿；`chart.svg`
保留图表源输出，标题和正文仍由 HTML 排版。风格主要由字体角色、蓝粉油墨
关系与共同对齐轴维持；不需要在报告里塞植物素材。

只有峰值唯一且观测窗口完整时，才使用这份「峰值时刻差」摘要。平台峰、
缺测或不同观测窗口应换摘要和构图，而不是编造一个峰值时刻。

# 城市与水 · 水墨证据报告

> 使用 MuseDraw 的水墨宣纸风格，制作一页横版概念研究报告，标题「让雨，留下来」。左侧用雨水花园场地意象和疏密节奏表达构想；右侧用随附 data.json 中两条示例曲线，展示各自峰值、时刻，以及 B 相对 A 的峰值变化。图像是想象概念，数据是独立的虚构演示，不把两者描述成真实设施试验。标题可保留书写感，单位、数字和曲线标注要准确易读。交付报告图片、实际输入、计算结果和可编辑排版。

随附 `data.json` 是完整输入，`artwork.png` 是原创生成的场地概念插画。
用 Skill 的 `scripts/build_visual_report.py` 构建到新目录，再用浏览器导出
1800 × 1200 报告。更换场地意象时使用主机图像工具和 `asset-prompt.txt`。

这份例子把水墨用于场地和标题，证据列保持常规字形与清晰坐标。
允许曲线峰值增长或持平，结果必须保持符号；变化百分比不是效果证明。
参考峰值为零时不能给出相对变化百分比。图表输入和插画均不能冒充实测。

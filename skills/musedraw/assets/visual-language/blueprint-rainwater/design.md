# 雨水利用概念剖面

把主路径接到屋面、沉砂、蓄水与花园这些实际部位。以黄色供水、蓝色虚线溢流区分两种路径，剖面和检修口提供空间证据。它不是制造图；没有尺寸或性能数据时不补写工程参数。

## 使用与改编

从此目录复制 `scene.json` 后，使用已安装 MuseDraw 的 `scripts/musedraw.mjs render` 渲染。修改 `nativeSvg` 可编辑图形与文字；此画面是手工构图源，不是自动重排算法。

先看 `preview.jpg` 和 `prompt.md`。保留虚构/概念示意的说明，真实任务需替换事实及来源。系统字体会改变字形与换行；以实际出图为准。此范例经过本机看图检查，非跨模型稳定提升证明。

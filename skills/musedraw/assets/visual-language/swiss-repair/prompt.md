# 修补日 · 瑞士海报

> 使用 MuseDraw 的瑞士海报风格做一张竖版修补日海报，主题「带一件旧物来，把它再用久一点」。主标题可以用 STILL GOOD.，中文标题为「修补日」。2026 年 11 月 21 日 13:00—17:00，溪岸社区工坊；衣物织补、旧书修护、小木器修整；提示带一件适合手工修护的旧物。用织物和修补针脚做主视觉，把信号红放到实际修补关系里。保留黑白红、强字形与非对称对齐的家族特征，按新对象重新组织文字与图像。虚构概念活动要注明，交付图片和可编辑排版。

本目录的 `index.html`、`artwork.png` 与上一级 `shared.css` 是完整原稿。
新增照片式素材使用主机图像工具与 `asset-prompt.txt`；也可复用随附原创素材。
标题与活动文字留在 HTML。没有图像生成工具不能把素材重放称作新生成。
本稿的红色由织物针脚承担，不要求每张瑞士海报都有同样的红色页脚。

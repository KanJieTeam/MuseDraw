# MuseDraw visual language

Develop the existing styles in the [style atlas](style-atlas.md). A named style
is a starting vocabulary for making an appropriate composition, not a request
to turn the subject into nodes, recolour a fixed layout or combine every available
effect. Keep the user's chosen style and the requested production medium.

Within [MuseCore](musecore.md), style orchestration works with expression and
visual conception to form one work proposal. Establish its type/image/space/
material relationship while composing; a named theme is not a finishing filter
on an unrelated layout. The family resources below remain choices, not steps.

For a ready-to-open work in any of the twenty families, use the
[complete style compositions](style-studies.md). Its small registry searches
28 original editable works by style or subject; read only the chosen work's
brief and design decisions.

## What a style should carry into a new work

Carry a recognisable relationship between **type, image, space and material**.
Choose a subject-specific visual idea inside that relationship. The useful
distinction is between a stable family and a repeated picture:

- Swiss can make a seed exchange feel like a large editorial specimen, and let
  a repair event's red stitched join carry the accent. Both can use the same exact red,
  grotesk type and asymmetrical alignment without repeating the seed or its layout.
- Riso can express seed dispersal through overlapping organic ink plates, and
  a music event through rhythmic impressions. Retain the ink logic, not the plant.
- Ink wash can use a seed head's bent stem to lead a vertical reading path, or
  a broad landscape interval to open a horizontal report cover. Retain the
  balance of concentrated ink and open paper, not a compulsory mountain or seal.

For original expressive work, decide the **main visual action** together with
the style: what stretches, opens, accumulates, connects, folds or contrasts?
Let that decision organise the image and headline. Ordinary informational work
can keep a straightforward structure; a metaphor is not required everywhere.

For an original named-style work, choose a working kit below or inspect one
relevant complete source before choosing component treatments from `themes/`. In the
Bauhaus project study, a large circle carries an actual completion quantity,
while a separate typographic field carries the work and dates. The transferable
decision is the contrast between those reading roles; a diagram with three
capabilities does not thereby need three different primary-colour shapes.
Use the selected theme JSON for exact palette and font settings after deciding
the spatial argument. Shape, border, shadow and heading defaults are available
component treatments, not instructions to apply every treatment to every object.
In HTML, plotting or image work, translate the roles to that medium. Preserve
chart encodings, distinctions and legibility when choosing a palette.

## Working kits for new subjects

Two families now include tools that can participate directly in making new work:

- [Swiss](style-kits/swiss.md): object/type opposition, a meaningful signal
  colour, editable silhouettes, document forms, type roles and HTML grid tools.
- [Ink Wash](style-kits/ink-wash.md): subject-led contours, ink-weight variation,
  open-field composition, optional vertical display and precise evidence type.

Read only the selected guide. `scripts/style-kit.mjs --style FAMILY --out NEW_DIR`
copies its drawing module, scoped CSS and a minimal authoring file. This starts
an original composition rather than replaying a finished case. Use a complete
study when its established composition is helpful; neither route is compulsory
for unrelated work. These kits are development resources, not a claim that
other hosts have acquired the author's aesthetic judgement.

## The existing twenty families, expanded beyond boxes

These are starting choices, not claims of historical authenticity or universal
quality. Each row describes a different compositional resource; choose the one
relevant to the brief instead of loading the whole table for every job.

## What the cross-subject studies made executable

**An accent can change jobs while the family stays recognisable.** The Swiss
seed poster uses red for an information band; the repair poster lets red appear
in the subject's stitches and a punctuation mark. Preserve a family relationship,
not the location of an accent strip. Before selecting a colour treatment, ask
whether the subject itself has a meaningful place for it.

**Material treatment follows the role of a mark.** Riso's botanical study can
have porous ink and a slight register offset. In the report, keep measured line
coordinates and symbols sharp. Translucent fields share the same zero and overlap
without stacking; they can carry the overprint relationship. They do not imply a
third measured series, and grain must not change apparent point values. Treat
this as one available expression, not a requirement to fill every chart.

**Use a different typographic voice for evidence when the medium needs it.**
The Ink Wash poster uses vertical handwritten display. The report keeps brush
character in its headline and landscape-shaped illustration, while its units,
data marks and explanatory column remain conventional and readable. Do not
apply calligraphy or irregular brush edges to the entire evidence field.

Rebuild the report studies from the adjacent `data.json` files with:

```sh
python <skill>/scripts/build_visual_report.py <skill>/assets/visual-language/riso-report/data.json --out output/rhythm-report
python <skill>/scripts/build_visual_report.py <skill>/assets/visual-language/ink-report/data.json --out output/ink-report
```

These two bounded compositions use the existing plotting helper. They need two
complete nonnegative series at the same supplied observation times; the rhythm
summary additionally needs a unique peak per series. A plateau, missing values,
different windows or an unsuitable reading task calls for a different summary
or composition, not invented values. Zero reference peaks have no relative
percentage change. The examples identify all observations as fictional.
Positive and negative peak changes preserve their sign; neither means a proven
benefit. Keep an illustration's concept role distinct from measured evidence.

## Reports whose typography and data carry the visual idea

The three office compositions make the style visible through scale and placement,
without requiring a decorative image. Editorial puts the argument at display
scale and the derived rate at another focal scale. Bauhaus lets an actual
completion quantity occupy a primary-colour circle while the right field carries
dates and work. Journal pairs a view of observations with a view of differences;
shared row identity carries the relationship. These are three task-specific
solutions, not instructions to add giant numbers or a second chart everywhere.

```sh
python <skill>/scripts/build_office_report.py <skill>/assets/visual-language/office-business/data.json --out output/business
python <skill>/scripts/build_office_report.py <skill>/assets/visual-language/office-project/data.json --out output/project
python <skill>/scripts/build_office_report.py <skill>/assets/visual-language/office-research/data.json --out output/research
```

Use a fresh directory. It contains editable HTML/CSS, PNG plots, original data
and derived values. Plots remain editable through the data and Python source.
Use the installed plotting environment and check installed Chinese fonts before
browser export. Recheck headline claims after changing data: the builder updates
numbers, not editorial judgement. These bounded layouts accept 3–8 income/cost
periods with positive income, 3–6 project milestones/work packages, or 3–10
nonnegative paired observations. Missing scientific values, signed absolute
observations, other measures or denser content call for an appropriate adaptation.
An unfinished milestone has no invented actual date. Project completion uses
supplied work weights; late completions and overdue unfinished nodes remain
distinct. An increase in a paired reading establishes neither benefit nor cause.

## Develop the family without making everything look the same

When extending a family, retain the palette/type/material relationships that
make it recognisable and change the subject, silhouette, reading path or image
scale as the new content warrants. Keep a successful reference visible when the
host supports it. Judge the finished image at its intended size and as a thumbnail:
does the main visual idea survive, and is the essential content still usable?
Automatic geometry checks cannot answer that aesthetic question.

External Skills can contribute a useful production decision—an asset strategy,
an image/type relationship or a method for maintaining a family. Rewrite it in
MuseDraw's existing vocabulary and make a new work with it. A source's particular
font pairing, layout or output preference does not become a universal rule.

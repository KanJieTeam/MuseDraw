# Evidence-chain panels（候选能力）

`evidence-chain` 面向同一个读者问题需要总览、可比面板和细节证据的科学图。它不是 Nature 原图的复刻，也不从预览像素重建统计。

## 输入契约

- `categories` 是所有面板共用的离散顺序，3–12 项；
- `groups` 是跨面板稳定的身份编码，颜色只承载组身份；
- 每面板必须声明且只声明一个角色：`overview`、`comparison`、`detail`；
- 每面板必须声明 `sampleDefinition` 与 `sourceIds`；每个来源 ID 必须在 `sources` 中存在；
- 所有数值来自调用者，所有面板共用从 0 开始的线性纵轴；误差只接受同长度的 `low` / `high`，不会被解释为置信区间；
- 画面在总览、比较、细节之间保持共同类别、组身份和尺度；细节不能偷偷换标尺。

## 拒绝边界

缺少共同类别、来源或样本定义；从面板标题猜测组身份；不确定性长度不匹配；负值或非有限值；需要不同单位或不同时间轴；想从图片像素回算均值、误差或显著性，均应退出该能力。

## 可观察检查

1. 三个角色是否各自回答不同问题，而不是同一张卡片换标题；
2. 同一类别在各面板是否落在同一序列位置；
3. 颜色隐藏后，组身份能否由图例和标签恢复；
4. 细节面板的误差是否贴近数据，且没有被写成未提供的统计结论；
5. 缩略查看时，读者是否仍先看到总览，再看到比较，最后看到细节。

当前示例是合成教学数据，审美尚未获得用户批准；此候选需要至少五个封存题和宿主转移测试后才能升级。

# Measured vertical capacity for the existing loop trace

The integer arithmetic, condition/body/accumulate/update events and twelve-round limit remain entirely in loopTraceModel. No range algorithm, Python parser or interpreter is added. The source fixture uses comparison< and bound6 to express the exclusive stop of range(1,6); its note distinguishes the next boundary candidate6 from Python's final loop-variable binding5. Empty ranges do not claim whether a variable was previously bound.

cap2LoopMeasuredLayout receives the existing finished SVG. It measures each native text node in its actual role, size, weight and font. Text pairs sharing horizontal space, containing rectangles, horizontal rules and canvas margins supply vertical line-box capacity constraints. If all original positions fit, the same SVG is returned without mutation. The original Windows default SVG and PNG are byte-exact.

When capacity is insufficient, one computed vertical factor enlarges all baselines, rectangle heights, rule/arrow points, canvas height and corresponding layout geometry together. Text sizes, wording, horizontal positions, widths, numbers and trace events are retained. There are no manually supplied positions, per-input adjustments, backing masks or font reduction. The fallback uses compositionReference. Horizontal text collisions, orphan prose punctuation or a required height above8000px explicitly refuse rather than discard content. Existing model/text/canvas limits still apply. This is a conservative vertical capacity fallback, not a general page optimiser.

The scratch patch wraps only the existing loop figure's final SVG and inserts the helper before loop-figures.mjs in browserBundle. Existing loopFamilies route remains. The source fixture index entry is optional; no family registration is added. Shared files are unchanged by this lane.

Browser tests use actual Noto SC/CJK with normal and+40 fontBoundingBoxAscent pressure, including positive/negative step, empty range, twelve rounds and long complete notes. Set MUSECORE_NOTO_FONT, its legacy alias, or install a standard Noto font; absence fails and is not skipped. Output evidence also compares1518 cases against Python built-in range. Passing execution/geometry checks does not establish aesthetic approval.

The exclusive bound and empty-sequence rules follow the [Python range documentation](https://docs.python.org/3/library/stdtypes.html#ranges). The distinction between the next boundary candidate and retained loop target follows the [Python for-statement reference](https://docs.python.org/3/reference/compound_stmts.html#the-for-statement). This fixture illustrates those bounded rules without executing supplied Python code.

Ordinary CLI discovery uses this example’s declared reference. Shared family registration is included in the main integration; measured tests and package verification remain separate from aesthetic approval.

# Deterministic grid value iteration

`grid-value-iteration` computes values and a greedy policy from explicit known toy-grid dynamics, then reuses the existing `rl-trajectory` renderer and validator for a bounded execution trace. It adds native policy arrows in every traversable nonterminal cell and a measured explanation panel. Existing supplied-trajectory behavior is retained.

Input uses the trajectory title/subtitle/view/evidenceKind/agent/environment/rewardUnit/gamma/grid/initial/note fields, with family `grid-value-iteration`, no supplied steps or focusStep, and every stateValue explicitly null. Every traversable entryReward must be a finite number in -1000..1000, including terminal states; blocked cells retain null rewards. The known row-major grid is2..6 rows/columns. Gamma is0..0.99. This is a model calculation, not learning from observed trajectories.

`solver` requires wallRule `stay-and-receive-current-entry-reward`, actionOrder containing the four distinct cardinal directions, valueTolerance1e-9..0.001, maxIterations1..2000 and traceLimit1..24. Outside/wall actions remain at the current state and receive its entry reward; terminal continuation value is0. First exact numerical maximum in the supplied actionOrder wins. Reaching a terminal ends the trace; reaching traceLimit truncates it. Positive-reward loops may therefore be preferred to a goal, and unknown dynamics or rewards are refused.

Synchronous updates use `Vnew(s)=max_a(reward(next)+gamma*Vold(next))`. After updating, the implementation measures `delta=max|T(V)-V|`, stopping only when `delta/(1-gamma)<=valueTolerance`; exhaustion explicitly refuses. The displayed approximate value error bound is delta/(1-gamma), and the conservative greedy-policy loss bound is2*gamma*delta/(1-gamma)^2. These are floating point estimates using contraction inequalities, not rigorous interval arithmetic guarantees. State and action labels, explicit rewards, note and supplied provenance declaration remain available in output metadata. Null stateValue means “compute”, never a supplied zero reward.

Bellman update, discounted contraction and greedy policy extraction follow the [UC Berkeley CS188 value iteration notes](https://inst.eecs.berkeley.edu/~cs188/textbook/mdp/value-iteration.html). Error-bound expressions above follow algebraically from that contraction and the greedy Bellman residual. No text or visual artwork is copied from the notes.

Composition reference: s08-qianghua-xuexi. The5×5 example adapts the existing explicit maze input and independently computes its values/route. It is not an observed environment or complete source reproduction. Keep the supplied-trajectory example and its capability; source-index movement is a separate integration decision.

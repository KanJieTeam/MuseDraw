# 有限单人周计划分配：199来源与范围

`weekly-greedy-allocation` 从明确任务、固定占用和有限槽规则计算日程，随后用同一任务ID连接四象限与日历。它不是最优排程器，也不判断工作真的完成。原 `planner` 继续接收调用者给定的 sessions；本能力不改变原模型或原默认。

## 默认输入的身份

`weekly-eisenhower-allocation.json` 是**合成教学输入**，不是源日程的转录。任务、固定占用和两个未命名短占用都是明确给定的合成数值。K1为周二09:15–09:30、K2为周四09:30–09:45；程序不补会议名称。默认计算45h工作时窗、9.75h实际固定占用、35.25h物理空闲、34.5h可排整槽、0.75h槽化损失、21h已排、13.5h留白；Q4另排除2h。没有拟合来源32/19/13。

`evidenceKind` 的 synthetic/supplied/source-adapted 值是调用者的来源声明，不是程序验真结论。图的 `compositionReference` 只记录构成参考，不对任意输入硬断言原稿来源。

## 有界输入

只接受严格结构字段，不执行自由文字或代码：

- 一人、2–7个有序日标签，数组就是日次序。每天同一整数分钟工作窗，0≤start<end≤1440，跨度≤720；不跨夜、不推日期/节假日。
- `slotMinutes` 15/30/60，时窗必须整除；槽以给定start锚定。最多336槽。
- 1–18项任务：唯一ID、名称≤90字、明确重要/紧急/可拆布尔值、正整数整槽时长≤5040min、已知截止日ID或显式null。未知截止日不作无截止日。
- 0–28项固定占用：唯一ID、给定标签≤80字或显式null、已知日、工作窗内正整数分钟区间。可以部分触及槽；同日占用不可互相重叠（相接允许），重叠请先明确合并。完整原记录保留。
- 标题≤90字、副标题及note≤300字，0–6条显式假设（每项≤220字）。固定字号按实测字形重排；超出该构成的行数预算明确拒绝，绝不截断用户note或缩字号。
- 不接收用户sessions、任务依赖、多人数资源、释放时刻、动态优先级、自动日期、未知指标、最优性目标或自由布局坐标；不支持字段立即拒绝。

必填policy为 `order:Q1-Q3-Q2`、`deadlineBoundary:inclusive-day-end`、`partialSlotBlock:any-positive-overlap`、`tieBreak:input-order`，另明确 `q2SlotOrder` 与在槽边界上的 `morningEndMinute`。

## 确定性计算

全部区间 `[start,end)`；仅相接不冲突，正长度相交就使整槽不可排。原固定占用仍按真实分钟尺度绘制；额外保留片段用独立斜线表示，不把15分钟涂成30分钟。

Q4保留原任务和估计，状态excluded、原因quadrant4-excluded-by-policy，不进队列。Q1→Q3→Q2；Q1/Q3按截止日排序、null最后、并列输入序，Q2输入序。截止日包含当天工作窗结束。Q1/Q3按日/时间；Q2明确选择逐日chronological，或全周上午槽优先再全周其余槽。后者可能先排后一天上午、再排前一天下午。上午边界可等于工作窗端点。

可拆任务依候选次序选空槽；不足时保留已分配部分与剩余分钟。不可拆任务找第一段同日连续足量空槽，否则不分配部分；上午偏好仅排序开始时刻，连续段可以越过上午界限。没有回溯。已选槽按同任务同日相邻合并为session。

未排原因只描述**当前贪心顺序后的余槽**不足或无连续段，不推出全局不可行、实际逾期或任务被取消。测试保留真实反例：30min任务先占上午首槽，随后90min不可拆任务无连续段；交换安排却可两项都排，证明不保证最优。

`allocateSinglePersonFiniteSlots` 是受包装层前提保证的internal bounded API，非用户入口；它仍验证同长15/30/60整数槽、有效日序号、物理不重叠、唯一槽索引/任务ID和有效不重复候选引用。包装层负责完整共同槽网格、队列与候选顺序。

账目独立输出并严格等式：

1. 物理空闲 = 工作总分钟 − 实际固定占用 = 可排整槽 + 槽化损失。
2. 可排整槽 = 已排 + 留白整槽。
3. 全任务估计 = 已排 + 应排未排 + Q4排除估计。

零可用容量是合法结果；未排与Q4排除仍区分，不产生零时长session。

## 构成与验证

四象限按真实任务文字计算行高；同一ID/名称/颜色连接实际计算的日历。日历纵轴是真实分钟，日列为给定顺序。短未命名占用的完整ID/起止就近放该日列头，其他放不下的原占用全名与时段保留附注。灰条不为可读性拉长，额外整槽保留独立编码。全部用户假设和note保持完整。

# 判断树（decision-tree）

这是一张用于办公审批、科研筛选和报告复核的条件判断图。输入只描述一个问题、显式判断节点、出口节点和分支标签；MuseCore 根据树结构计算层级、节点位置与正交连线，宿主不需要手动移动坐标。

## 输入范围

- `nodes` 为 3–18 个节点；每个节点是 `decision` 或 `outcome`，并声明 0–4 的层级。
- 只有一个 0 层判断节点；除根节点外每个节点恰有一个父节点，判断节点有 2–4 个出口。
- `edges` 为 2–24 条相邻层级的有向边，每条边带有原始分支标签；所有节点都必须从根节点可达。

## 拒绝条件

缺少根节点、重复节点、重复边、循环、孤立节点、跨层跳转、出口继续分支、过长文本或超过层数/节点数上限时拒绝生成。程序不推断概率、置信度、责任人、时间或推荐结论；这些内容必须由输入明确提供或省略。

## 验证

运行 `node scripts/musecore.mjs render assets/musecore/decision-tree-demo.json --out output/decision-tree`，再运行 `node --test tests/musecore/decision-tree.test.mjs`。测试覆盖桌面渲染、390/1024/1440 窄屏预览、中文字体压力以及结构拒绝边界；几何审计失败或文字越界都不能交付。

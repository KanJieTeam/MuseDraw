# Bounded language teaching constructions

`character-structure` displays two to twelve characters from its explicit
verified catalogue. Component order, teaching decomposition and broad spatial
zones come from the catalogue, not visual guessing or arbitrary string slicing.
Colour zones indicate approximate component placement; they are not stroke
outlines, handwriting proportions or etymological claims. Unsupported characters
leave this route. Read the example and model catalogue before selecting items.

`tense-timeline` supports two to six affirmative teaching templates using six
pronouns, explicitly catalogued verb forms and seven declared example contexts.
The example sentence is checked against its selected template. Each row shares
the speaking-time reference but is not elapsed-time measurement. Repetition
marks illustrate a habit, not counted observations. Present-perfect examples
remain connected to the present rather than an invented dated past event.
This is not a free-text grammar parser or a complete English tense/aspect system.

The family controls character zones, example typography, row spacing and
time-reference objects. It does not ask the host to invent new coordinates.
Long content reflows inside the declared budget or is rejected; unsupported
grammar and catalogue content should use another route.

Run `core example character-structure` or `core example tense-timeline`, then
`core render` using the generated JSON. Mechanical and font checks do not
substitute for reviewing the finished teaching sheet.

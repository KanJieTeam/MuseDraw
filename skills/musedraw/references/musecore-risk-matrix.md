# 风险矩阵（risk-matrix）

这是一张供办公计划、科研项目和运营复盘使用的二维风险登记图。横轴和纵轴必须由调用者提供离散等级与分值；程序只计算两轴分值的乘积，并把结果落入调用者声明的三个连续区间。圆点只标识登记项，右侧登记表保留责任人与应对动作。

## 输入范围

- `xAxis.levels` 与 `yAxis.levels` 各 2–5 个等级，分值是 1–5 的互不重复整数。
- `bands` 必须是三个连续、无间隙的整数区间，覆盖所有可能乘积；程序不替调用者选择阈值。
- `items` 为 1–18 项，每项必须声明可能性、影响、负责人、应对动作与 `open`、`watch` 或 `contained` 状态。

## 拒绝条件

缺少等级或状态、等级分值重复、风险区间有间隙、条目引用不存在的等级、超出条目数量或文字上限时拒绝生成。图上不填造概率、损失金额或因果结论；分值只代表输入方声明的相对排序。

## 验证

先运行 `node scripts/musedraw.mjs core render assets/musecore/risk-matrix-demo.json --out output/risk-matrix`，再运行对应测试。测试覆盖 390/1024/1440 窄屏页面、字体高度压力、超界文字、断档阈值和未知等级；几何审计失败或内容越界都不能交付。

# PCR：原稿给定的合成引物示例

`pcr-primer-source.json` 是现有 `primer-pair` family 的独立来源输入，不替换 `primer-pair.json`，不新增引物设计、热力学或排版引擎。

来源为 [180原SVG](../../../gallery/collections/visual-cases/180-pcr-primers/source.svg) 与 [作者说明](../../../gallery/collections/visual-cases/180-pcr-primers/author-notes.md)。原SVG SHA-256：`392af93cb2fa332cf5c3fa1faff534b5e6b21f35738052770a851d4987b0a9e3`。模板由原SVG的五行、每行60个碱基文本直接拼合，共300个碱基；没有重新生成随机模板、从像素推断序列或把它称作真实基因。所有序列均为作者明确的合成教学示例。

## 不同计算口径须分清

现有模型只计算字符与几何：给定范围匹配、长度、GC、显示上链的完全匹配出现位置、连续反平行Watson–Crick互补段。出现位置并非全基因组特异性检索。输入参考带为18–25 nt、40%–60% GC，只描述是否落入给定带，不是引物设计通过条件。

原稿写“自身互补最长2个碱基”，对应这里的任意位置连续互补：F/F=2、R/R=2；现图核对栏明确用触及至少一份拷贝3′端的连续段，分别为1和0。这两项定义不同，不将原稿的2硬填为端部统计。F/R两口径均为3。反例 `TCAGGACTAGCTAGGCGCGC` 的任意位置最长段为8，触及3′端的最长段为6；图画出实际6对碱基，不据此断言真实二聚体一定形成。

原SVG按 `64.9 + 41 × (G+C − 16.4) / N` 给出Tm约53.8/54.8°C。按此文字公式独立核对为53.83/54.83636…，与原稿舍入一致；这些仅是**来源给定的经验估值**，资产note明确归因。当前模型 `tm:null`，卡片显示“未计算”；没有新增Tm计算或输出已计算的温度，也不验证原估值、退火温度、盐/浓度条件、发卡或二聚体稳定性。原稿相关验收勾选与“会形成二聚体”结论不作为本能力已验证结果。[Primer3官方手册](https://primer3.org/manual.html#PRIMER_TM_FORMULA) 说明最近邻、盐校正与浓度条件下的Tm计算；[热力学寡核苷酸比较](https://primer3.org/manual.html#PRIMER_THERMODYNAMIC_OLIGO_ALIGNMENT) 与本图的连续字符计数是不同操作。

## 使用与退出范围

沿用既有输入边界：明确 `synthetic-teaching`；60–360个大写ACGT模板；12–30 nt给定引物；1基含端点且不重叠、相向的结合范围；有界完整文字与描述性参考带。未知碱基N、错误方向/序列、猜测的Tm字段或真实基因模式应拒绝，不补造未知结果。

复用现有点阵笔记、模板高亮、两张引物卡、核对栏与互补示例构成。正常源输入原生画布为2900×1561，原稿为1600×1000；更大的画布和额外方向示意是既有构成代价，不声称原图全部内容或视觉比例已复刻。原有默认与Grover能力不变。数值、几何核验和实际成图审阅分别记录，不把通过检查称作审美通过。

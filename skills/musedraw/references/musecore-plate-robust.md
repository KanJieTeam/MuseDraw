# Given-observation plate screening with an optional robust threshold

`plate` keeps its original fixed numeric `threshold` / `direction` branch unchanged. A new mutually exclusive `thresholdPolicy` branch accepts `median-mad`, `population: non-control-wells`, explicit `scaleFactor` in(0,10], `multiplier` in[0,10], `direction: above|below` and `comparison: inclusive|exclusive`. It is not an assay optimizer. `plate-robust-screen.json` is a clearly synthetic teaching fixture using supplied observations, not reconstructed source measurements.

## Bounded input and literal classification

Four to sixteen unique row labels (one to three Unicode characters), six to twenty-four integer columns, a complete row-major array of finite numeric values and a declared increasing range are required. Numeric observations and range bounds are within[-1e6,1e6]; units are explicit. Generated well IDs must also be unique: row `A1` / column1 cannot silently collide with row `A` / column11. Each positive/negative control set declares one to three columns, without overlap; at least one non-control well remains. Missing or null observations are rejected, never zero-filled. The new branch accepts full title/subtitle/dataStatus and an optional full note, but no free coordinates, normalization, automatic policy, raw-fluorescence conversion, significance or efficacy claims. Root fixed `threshold` and `direction` are rejected in this branch, rather than choosing an implicit winner.

The median averages the two central observations for an even count. MAD is the median of absolute deviations from that median. Robust SD equals the supplied factor times MAD; threshold is median plus/minus multiplier times robust SD. Ordering and classification use exact BigInt rational arithmetic parsed from each canonical JavaScript Number decimal string. Original numeric token spelling lost before input is not recovered. Consequently0.30000000000000004 remains different from0.3. Ties are classified by the supplied comparator; hit ordering is value-first in the declared direction, then original row-major index. A zero multiplier and zero MAD are valid literal rules. Zero spread is explicitly shown and does not establish biological activity or a noise floor.

A calculated threshold can lie outside the declared observation range. It is not clamped: the full off-scale status is printed, without drawing a false in-range threshold line. In-range threshold positions use the declared observation scale. Histograms count non-control observations with twelve equally spaced bins; upper endpoints belong to the last bin. Five scale positions are exact rational interpolations of declared range bounds. If full numeric labels would collide or have to be rounded, the scale uses低/¼/½/¾/高 and explicitly prints both complete given endpoints and the fractional-position convention; close but distinct endpoints are never all labelled0.3. Empty bins retain zero counts in the model but emit no zero-height graphical object. Color intensity is the declared value scale, not a probability or p-value.

## Controls, numeric display and complete evidence

Control means and sample variances are exact rational calculations; sample SD and Z-prime are numerical approximations marked with≈. Z-prime is1−3(SD_positive+SD_negative)/absolute(mean_positive−mean_negative). Exactly equal control means produce an explicit undefined state, not0. Very small SD values retain scientific displays rather than being called zero; numerical values outside Number representability are null with a defined display/reason. Exact mean/variance and threshold numerators/denominators remain in geometry. Terminating rational displays up to24 characters print exactly; longer or recurring values use≈ at seven significant digits. Classification always uses the complete rational, never those display strings. This is an explicit statistical convention for supplied data, not validation of control quality, sample efficacy, dose response or significance.

The plate, black hit outlines, threshold, distribution and full hit rows consume the same computed model. Up to ten hits use a complete side list; larger sets use an actual rendered detail region, with a data-driven two to eight columns. No hits are replaced by a referral to the input file. All352 possible non-control hits of the maximal384-well configuration remain rendered and individually keyed. Individual raw hit numeric strings are complete and units appear in each column header. The renderer expands width from1600 as numeric columns need space; the tested352-hit page is1980 wide,3713.8 high normally and6679 high with+40 ascent. Fixed title/body/list sizes are60/24/23px. Font ascent/descent determine row spacing. Excessive combined text beyond the8000px canvas budget is rejected, not clipped or scaled down. This is a bounded report, not an arbitrary full laboratory report layout.

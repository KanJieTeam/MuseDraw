# Material objects as poster construction

One shared thin construction module serves `book-repair-poster` and
`coffee-pour-poster`. Shared date, event and measured typography rules support
two different objects rather than replacing them with a generic card template.

The book view recomputes title-slip columns, visible page edges, three to six
binding holes and a bounded repair-patch proportion. Right-to-left vertical
columns, thread, paper and text belong to the same object. These are schematic
material choices, not conservation instructions or a historical binding claim.
The coffee view recomputes a normalized Archimedean spiral, cup/handle/saucer and
event typography. Equal spiral spacing is a compositional device, not a flow,
extraction, temperature or pouring simulation.

Use `core example book-repair-poster` or `core example coffee-pour-poster`, inspect
the bounded fields, then `core render`. Dates, venue, sessions, seats, opening
hours and offer text are supplied examples or facts; they are not invented by
the renderer. Long titles and event text must reflow inside the declared budget
or leave this route. User notes stay intact, while implementation scope belongs
in metadata and this reference. Test success is not aesthetic approval.

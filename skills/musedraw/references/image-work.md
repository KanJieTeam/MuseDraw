# Image work

Use this route for painting, photographic imagery, textured illustration and
image edits when a raster asset is the appropriate result. It complements the
native scene renderer and the HTML/CSS/JavaScript route.

## Choose and execute

Use an available image-generation/editing tool in the current host, following
that tool's own instructions. Inspect the selected reference and pass it to the
tool when supported; words alone do not carry its composition and material.
Keep the user's requested subject, proportions, color relationships and medium.
For a new interpretation, retain useful visual decisions while creating the
requested new content. For an edit, preserve unrelated approved parts.

For posters or brand compositions, choose whether typography belongs in the
generated image or in a native vector/HTML layout. Prefer a separate text layer
when exact spelling, editable type or repeated content changes matter. Deliver
the actual requested artifact rather than forcing every image through a scene.

If no suitable image tool is available, report that the current host lacks the
required image capability. Offer saved asset reuse or a different medium only
when useful to the user; do not quietly replace a painterly or photographic
reference with geometric placeholders. Do not describe this host limitation as
MuseDraw being limited to architecture diagrams.

## Gallery handoff

A copied case brief can include its reference, original production prompt and
case-matched Skill link. Use that supplied Skill rather than an old installation
or remembered export instructions. For a native-vector case with a complete
scene, use the scene replay route; image synthesis is unnecessary there.

Reusing the saved original asset, rendering a native source, and generating a new
image are different operations. State which was performed. A new image from the
same prompt/reference can vary across models and runs; a saved image is not
evidence of regeneration. Preserve relevant factual caveats from the original
brief, including fictional scenes and illustrative scientific content.

## Delivery

Deliver the requested PNG/JPEG/WebP or other supported image format and a useful
preview. Retain the production prompt and any editable layout/source assets used
for revisions. SVG, scene JSON and scene checks are relevant only when the
actual production route uses them. Inspect the generated image for requested
content, composition, text and visible defects before claiming visual review;
report an unavailable or incomplete generation step plainly.
